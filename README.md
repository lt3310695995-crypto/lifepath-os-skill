# LifePath OS Skill

你的经历，由你确认；你的未来，保留选择。

一个中文 Agent Skill：帮助用户通过对话整理人生经历、核对事件、回顾转折，并探索可验证的未来选择。

## 能做什么

- 围绕一段经历进行自适应访谈，每轮聚焦一个问题，支持暂停、跳过、总结和继续。
- 将叙述整理为候选事件，保留模糊时间、原话依据和用户感受。
- 区分用户自述、助手观察和未来假设；事件由用户核对确认。
- 从具体经历中提出待核对的观察，以及成本可控的验证动作。
- 在具备 LifePath 工具时按真实接口读写，避免重复保存或虚报成功。

## 使用

将本仓库完整复制到支持 Agent Skills 的客户端技能目录，并将技能文件夹命名为 `lifepath-os`。保留 `SKILL.md` 与 `references/` 的相对位置；加载方式以所用客户端为准。

也可以让能读取本地文件的代理按本仓库的 `SKILL.md` 执行一次访谈。

示例请求：

> 使用 lifepath-os，帮我整理一次重要的职业转折。先聊聊，不保存。

> 帮我回顾大学毕业到第一次换工作这段经历，每次只问一个问题。

> 基于我已确认的经历，梳理这个选择的前提、风险，以及一个小规模验证动作。

## 两种使用方式

**仅对话**：无需 LifePath 后端即可整理经历；内容不会由本技能写入 LifePath 数据库，也不承诺跨会话记忆。

**连接 LifePath**：需要另行提供 LifePath V6.1 运行程序，以及可用的 MCP、CLI 或本地 HTTP 接口。接口字段与能力限制见 [持久化参考](references/persistence.md)。

本仓库只发布技能和参考资料，**不包含 Python 后端、网页程序或数据库**。参考资料中的 `python -m lifepath...` 命令必须在另行提供的运行程序根目录执行，不能直接在本仓库执行。

代理的自适应访谈与 V6.1 程序的固定三问访谈是两种不同流程。安装本技能不会自动改变网页行为，也不会安装或连接后端服务。

## 数据边界

“已确认”表示用户认可记录，不表示独立核实。技能不生成诊断或未来成功概率。

本地数据库不等于整个对话离线；代理使用的模型服务可能接收对话上下文。敏感内容需由用户明确要求保存，人生记录不会因使用本技能而被自动公开到 GitHub。

## 验证范围

技能格式及内部引用已经检查；持久化参考已与配套 V6.1 源码核对，并通过临时数据库验证候选、确认、编辑和删除等关键行为。行为情境是检查材料，不代表所有代理客户端已通过自动化兼容测试。
